# Mom Test Question Templates by Gap Type

Patrones de traducción de gap → pregunta de entrevista. Cada template sigue las 3 reglas Mom Test:
1. Habla de su vida, no de tu PRD
2. Pregunta por el pasado concreto, no por opiniones
3. Habla menos, escucha más — nunca confirmes tu hipótesis

---

## Por tipo de gap

### Problem Framing Gap
*No sabemos si el problema que asume el PRD existe o importa.*

Templates:
- "Cuéntame cómo es un día normal cuando [dominio relevante]. ¿Qué parte te lleva más tiempo?"
- "La última vez que tuviste un problema con [área], ¿qué pasó exactamente?"
- "¿Qué es lo que más te complica hoy en [proceso]?"

### Desirability Gap
*No sabemos si el dolor es suficientemente fuerte para motivar cambio.*

Templates:
- "¿Qué has intentado hacer para resolver [situación]? ¿Cómo te fue?"
- "La última vez que [situación problemática], ¿qué hiciste?"
- "¿Cuánto tiempo/dinero/esfuerzo te cuesta hoy [problema]? ¿Tienes algún ejemplo concreto reciente?"

### User Context Gap
*No sabemos los triggers, workarounds ni intentos previos.*

Templates:
- "¿Qué te hizo empezar a buscar una forma diferente de hacer [X]?"
- "¿Qué usabas antes de [solución actual]? ¿Por qué cambiaste?"
- "Cuando [situación] no funciona como esperas, ¿qué haces?"
- "¿Hay momentos en los que lo resuelves tú mismo sin seguir el proceso oficial? ¿Qué pasa entonces?"

### Process Functional (PF) Gap
*No sabemos cómo funciona el proceso AS-IS en detalle.*

Templates:
- "Cuéntame paso a paso la última vez que hiciste [proceso]. ¿Por dónde empezaste?"
- "¿Cuántas veces a la semana haces [tarea]? ¿Cuánto tiempo te lleva normalmente?"
- "¿Qué pasa cuando algo sale mal en [paso del proceso]? ¿Me puedes dar un ejemplo reciente?"
- "¿Qué herramientas usas durante [proceso]? ¿Hay algo que usas aunque no deberías?"

### Segment / Persona Gap
*No sabemos exactamente quién usa esto o quién decide.*

Templates:
- "Cuando [problema] ocurre, ¿quién más se ve afectado?"
- "¿Quién más en tu equipo/empresa hace [tarea]? ¿Lo hacen igual que tú?"
- "Cuando tuviste que [decisión relevante], ¿quién estuvo involucrado? ¿Cómo se tomó la decisión?"

### Usability / UX Gap
*No sabemos si los usuarios pueden ejecutar el flujo propuesto.*

Templates:
- "¿Cuándo fue la última vez que aprendiste a usar una herramienta nueva para [dominio]? ¿Cómo fue?"
- "¿Qué parte de [proceso actual] encuentras más confusa o difícil de seguir?"
- "¿Alguna vez has cometido un error en [flujo]? ¿Qué pasó?"

## Anti-patrones a evitar (confirmación de sesgo)

| ❌ Pregunta prohibida | ✅ Alternativa Mom Test |
|----------------------|------------------------|
| "¿Te gustaría que existiera X?" | "¿Cómo resuelves esto hoy?" |
| "¿Usarías X si existiera?" | "¿Qué has intentado antes?" |
| "¿El problema principal es X, verdad?" | "¿Cuál es la parte más difícil de [proceso]?" |
| "¿Crees que X sería útil?" | "La última vez que tuviste este problema, ¿qué hiciste?" |
| "¿Con qué frecuencia tienes este problema?" | "¿Cuándo fue la última vez? Cuéntame qué pasó." |

## Señales de datos malos (filtrar en análisis post-entrevista)

Descartar como evidencia:
- Cumplidos: "me encanta la app", "todo está muy bien", "hacéis un trabajo increíble"
- Opiniones sobre el futuro: "creo que estaría bien si...", "me gustaría que..."
- Vaguedades: "a veces", "más o menos", "depende", "en general"
- Hipotéticos: "si tuviera X, haría Y"

Conservar como evidencia:
- Comportamientos pasados con fecha/contexto: "la semana pasada cuando..."
- Workarounds concretos: "lo que hago es..."
- Frustraciones con impacto observable: "tuve que repetirlo 3 veces"
- Decisiones tomadas: "por eso cambié a...", "por eso dejé de..."
